Небольшой скрипт, который скачивает все вк-документы в папку.

Как пользоваться:
1) Открываете скрипт
2) Заходите на https://vkhost.github.io/
3) Копируете токен для своей страницы
3) Запускаете скрипт
4) Вставляете токен
5) Загрузка началась!

По умолчанию скачанные файлы будут сохраняться в созданной папке savefolder рядом со скриптом, но вы можете явно указать путь передав его в методе save_docs().
