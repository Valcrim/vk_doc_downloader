# VK documents downloader – небольшой скрипт для скачивания документов из https://vk.ru/docs

## Как пользоваться:
1) Открываете скрипт
2) Заходите на https://vkhost.github.io/
3) Копируете токен для своей страницы
3) Запускаете скрипт
4) Вставляете токен
5) Загрузка началась!

## Примечания
Вы можете задать некоторые параметры при вызове метода save_docs() в main(), чтобы изменить поведение скрипта:
- ```save_path```: указывает путь для сохранения файлов. По умолчанию скачанные файлы будут сохраняться в автоматически созданной папке savefolder рядом со скриптом.
- ```only_extentions```: фильтр на скачивание файлов с конкретными расширениями. По умолчанию скачиваются файлы всех раширений.
